## Purpose

Examples in this repository should demonstrate small, understandable implementation patterns for developers without exposing production credentials or internal infrastructure.

Examples may cover:

- SDK initialization
- Public API requests
- Authentication flow integration
- Pagination and error handling
- Webhook receipt and verification
- Minecraft server integration patterns
- Discord integration patterns

## Safe example policy

Every example must use placeholder values. Never commit real access tokens, refresh tokens, client secrets, private keys, bot tokens, webhook credentials, database credentials, account details, private endpoints, or personal information.

Example logging must also avoid printing secrets.

## Production use

Examples are educational starting points. Security, validation, error handling, rate limits, storage, deployment, monitoring, and platform-specific requirements should be reviewed before production use.
